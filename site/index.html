    Install

    1. Get the code. With Node.js 22.18 or later, run git clone https://github.com/SUNGMYEONGGI/Oh-My-Openpickle.git, then npm ci inside the folder.
    2. Open it in the browser. Run npm run dev and open 127.0.0.1:3210/app. Chats are saved in that browser.
    3. Or build the desktop app. Run npm run dist:mac, dist:win or dist:linux on that system. macOS builds are unsigned.
    4. Connect a model. Install Ollama and pull a model, then open My Pickle › AI connection and pick it.

    Questions

    What does it cost?

    Nothing. The app is free and runs a model you choose on your own computer through Ollama, so there are no API fees.

    Is this the Pickle app?

    No. Oh-My-Picklebot is an independent project inspired by Pickle's screens and flows. It does not use Pickle's servers, accounts or assets, and is not affiliated with its makers.

    Can I talk to a real AI right away?

    You start in demo mode, which answers with fixed rules and labels every reply. Install Ollama and a model, then connect it from My Pickle for real conversations.

    Where are my chats and memories stored?

    In the local storage of the browser or desktop app you use. Nothing syncs automatically, so export a backup before clearing browser data.

    Do reminders run when the app is closed?

    No. Reminders post into the chat while the app is open. They never run tasks or send messages outside.

    Is the interface in English?

    Not yet. Labels are in Korean. A local model answers in the language you write to it.

    Where can I download an installer?

    There are no published installers yet. Build one with the commands above; macOS on Apple silicon is the tested platform.
